# A fruit fly brain prices every swap

Static promo page for the Gas Killer fly-connectome AMM demo: the complete MaleCNS fruit-fly connectome
(166,700 neurons, 25.6 M synapses) simulated on-chain to set the fee of every swap on a Sepolia AMM,
settled through Gas Killer's unbounded profile.

Live page: https://gas-killer.github.io/fly-amm/

Contracts, tests and tooling: `src/examples/onchain-fly` in [solidity-sdk](https://github.com/gas-killer/solidity-sdk).
`viz/fly_amm_v2.html` is the built visualizer (regenerate with `tools/fly_viz_build2.py` after new rounds).
